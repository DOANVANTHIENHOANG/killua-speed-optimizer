## 📖 Giới thiệu (Overview)
**Killua Speed** là công cụ tự động hóa được viết bằng Python, thiết kế chuyên biệt để giải phóng tài nguyên hệ thống, dọn dẹp bộ nhớ đệm (cache) và tối ưu hóa hiệu suất cho máy tính, đặc biệt hỗ trợ duy trì sự mượt mà khi chơi các tựa game nặng. 

## ✨ Tính năng cốt lõi (Core Features)
*   **Deep Disk Cleanup:** Quét và xóa các file tạm (Temp, Prefetch) an toàn mà không ảnh hưởng đến hệ điều hành.
*   **Game Cache Maintenance:** Tự động nhận diện và dọn dẹp các tệp tin cache dư thừa từ các nền tảng game.
*   **One-Click Execution:** Tối ưu hóa toàn bộ hệ thống chỉ với một lệnh duy nhất.
*   **Lightweight:** Tiêu tốn cực ít RAM khi chạy ngầm.
